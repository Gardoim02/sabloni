# Šabloni

Kompaktna desktop aplikacija za Windows za šablone, brze beleške i sačuvane naloge.

## Preuzimanje

### [⬇ Preuzmi najnoviju instalaciju za Windows](https://github.com/Gardoim02/sabloni/releases/latest/download/Sabloni-Instalacija.exe)

Ovaj link ostaje isti i uvek preuzima najnoviju objavljenu verziju.

[Pregled izdanja i izmena](https://github.com/Gardoim02/sabloni/releases)

## Instalacija

1. Preuzmi **Sabloni-Instalacija.exe** preko linka iznad.
2. Pokreni instalaciju.
3. Otvori aplikaciju i napravi lokalni nalog sa username-om i Master PIN-om od 3 do 8 cifara.

Instalacija počinje prazna i ne sadrži tuđe podatke.

Potrebni su **Windows 10/11 x64**, **.NET Framework 4.8** i **Microsoft Edge WebView2 Runtime**.

## Ažuriranje

Zatvori aplikaciju, preuzmi novu instalaciju preko istog linka i instaliraj je preko postojeće. Tvoji podaci ostaju sačuvani. Pre ažuriranja pravi se automatska rezervna kopija.

## Mogućnosti

- Kategorije, šabloni i brze beleške.
- Kopiranje običnog teksta jednim klikom, uz očuvane prelome i prazne redove.
- Odvojene biblioteke i podešavanja po lokalnom nalogu.
- Sačuvani username-i, lozinke i linkovi.
- Import i Export šifrovanih kopija.
- Čuvanje poslednjih 5 automatskih kopija po nalogu.

Podaci se čuvaju lokalno na računaru.
